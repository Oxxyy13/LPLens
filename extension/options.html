Advanced connectionsCustom RPC endpoints and optional Etherscan access

Optional. Leave this closed unless you have a reason to change endpoints or add a key. Blockscout already serves lifetime history on Ethereum, Base, Arbitrum and Polygon with no key, so nothing here is required. An Etherscan V2 key is faster, and it is the only way to get complete Polygon history — polygon.blockscout.com silently misses positions below roughly tokenId 1.2M. Custom RPC URLs are for when a public endpoint rate-limits you.

Custom RPC endpoints

Leave blank to use the built-in public defaults. Your own Alchemy/Infura/dRPC URL is faster and more reliable. Alchemy's free tier still caps eth_getLogs at a 10-block range, so an Alchemy URL here does not replace a history source.

Etherscan V2 API key

Optional. Free key from etherscan.io/apis (Etherscan V2 is multichain). Faster than Blockscout on Ethereum, Arbitrum and Polygon. On Base, Etherscan's free tier refuses logs, so LPLens keeps using Blockscout there even with a key. Robinhood Chain needs neither: its public RPC already serves full-range logs.
