✓

Privacy by construction

The extension only asks for what it needs.

Your saved wallet addresses, settings, locally hidden-position choices, immutable event-history cache, and most recent rendered portfolio view stay in chrome.storage.local. The saved portfolio view is used only to make the browser side panel appear immediately and is replaced after a successful refresh. When you scan, LPLens sends the address and public-chain query data to the named RPC, price, and history services needed to return results. For a v4 position with later additions, the public transaction hashes are also sent to the chain's public Blockscout trace endpoint so principal and already-earned fees can be separated exactly. The LPLens service processes allowlisted Blockscout log filters; it does not store wallet addresses, filters, responses, or completed portfolio views.

There is no wallet connection, private key, or signing access. The beta service stores hashes of the access code and a random browser-installation identifier, plus first/last seen and daily relay-request totals. It does not store IP addresses or fingerprint the browser. Optional Uniswap and ProjectX page access is off at install and disclosed immediately below.

U

On-page overlays

Bring position context onto the protocol page where you use it.

LPLens has no access to any web page when installed. Each site below is independently optional. On Uniswap it reads the position-page URL; on the positions list it reads position links and the first line of visible row text to discover and label positions. On ProjectX it runs only on www.prjx.com/portfolio and uses the last address you loaded in LPLens; it does not read ProjectX page content or the connected wallet. It never reads balances, forms, signing prompts, or wallet-provider state, and it only appends its own panel. Turning a site off removes that permission and content script.

Optional. Leave this closed unless you have a reason to change endpoints or add a key. Licensed builds include access to the LPLens Blockscout Pro relay on Ethereum, Base, Arbitrum and Polygon, so nothing here is required. An Etherscan V2 key is an optional direct alternative, and it is still the only verified way to get complete Polygon history — polygon.blockscout.com silently misses positions below roughly tokenId 1.2M. Custom RPC URLs are for when a public endpoint rate-limits you.

Custom RPC endpoints

Leave blank to use the built-in public defaults. Your own Alchemy/Infura/dRPC URL is faster and more reliable. Alchemy's free tier still caps eth_getLogs at a 10-block range, so an Alchemy URL here does not replace a history source.

Etherscan V2 API key

Optional. Free key from etherscan.io/apis (Etherscan V2 is multichain). Faster than Blockscout on Ethereum, Arbitrum and Polygon. On Base, Etherscan's free tier refuses logs, so LPLens keeps using Blockscout there even with a key. Robinhood Chain's public Blockscout and RPC provide its history and v4 addition proofs without a user key.
